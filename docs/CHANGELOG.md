# Что нового

## 0.7.1

* Отчёты: код запроса и его результат — блок «Код запроса и результат», отчёт по сохранённому запросу из
  «Избранного», флажок «код запросов и результаты в конце отчёта», источник «Из избранного…» в конструкторе.
* LibreOffice находится в большем числе мест: реестр Windows, папки программ на любом диске и с номером версии,
  установка для пользователя, Scoop, PortableApps; в настройках можно указать папку; неверный путь в настройках
  больше не отключает автоматический поиск; после смены пути перезапуск не нужен.
* `main.py --find-libreoffice` и `bat\find_libreoffice.bat` — где программа ищет LibreOffice.

## 0.7.0 — этап 7: завершение

* Исправлено по первому запуску сборки на Windows: тесты интерфейса на настоящем PySide6 зависали на окне
  подтверждения; модальные окна в тестах больше не блокируют прогон.
* Тесты запускаются через `scripts/run_tests.py`: сторож прерывает зависший тест с выводом стека, подробный отчёт
  пишется в файл (`test-report.txt`, при сборке — `build-test-report.txt`), консоль не засоряется выводом журнала.
* Сборка при непройденных тестах спрашивает, продолжать ли (`build.ps1 -SkipTests` — без тестов).
* Запасной вывод журнала (до его настройки) тоже маскирует пароли.
* Чтение CSV не держит файл открытым (на Windows открытый файл нельзя удалить).
* Заглушка Qt в тестах больше не скрывает опечатки в именах методов интерфейса.

* Готовые батники для всех действий (`menu.bat` и папка `bat\`): установка, запуск, проверка окружения,
  тесты, интеграционные тесты, сборка .exe, задачи, экспорт и импорт настроек, диагностика, обслуживание.
* Командная строка: `--export-config`, `--import-config`, `--diagnostics`, `--paths`.

* Справка в программе: руководства пользователя и администратора, «О программе», проверка окружения,
  диагностический архив.
* Резервная копия настроек: экспорт и импорт подключений (без паролей), шаблонов, избранного, сценариев и задач;
  сброс настроек.
* Защита от двойного выполнения: одна копия программы на пользователя; задача не выполняется одновременно в окне
  и в Планировщике Windows.
* Уведомления в области уведомлений Windows, сочетания клавиш, значок программы.
* Сборка в .exe (PyInstaller): спецификация, ресурс версии, скрипт сборки с прогоном тестов.
* Исправлено: разделы «Сравнение БД» и «Документация» открывали заглушку вместо готовых страниц.
