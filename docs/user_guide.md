# Руководство пользователя DB Workspace Pro

DB Workspace Pro — рабочее место для Microsoft SQL Server: подключения, просмотр объектов, SQL-редактор, отчёты Word,
конвертер файлов, автоматизация, мониторинг, сравнение баз и документация. Программа по умолчанию **только читает**
данные: любое изменение требует явного разрешения и подтверждения.

## Начало работы

Если программа установлена из исходников, запустите `menu.bat` в папке программы: пункт `1` — установка, пункт
`2` — запуск.

1. Откройте раздел **«Подключения»** и нажмите «Создать». Укажите сервер (например, `SRV01` или `SRV01\SQLEXPRESS`),
   способ входа и базу данных по умолчанию.
2. Нажмите «Проверить» — программа покажет версию сервера или понятное описание ошибки.
3. Нажмите «Подключиться». Состояние подключения видно в строке состояния внизу окна.

Пароль (для входа SQL Server) хранится только в системном хранилище учётных данных Windows и только если отмечено
«Сохранить пароль». В файлы настроек и журналы пароли не попадают.

## Обозреватель

Дерево объектов: базы данных, таблицы, представления, процедуры, функции. Для таблицы доступны столбцы, ключи,
индексы и просмотр первых строк. Двойной щелчок по объекту открывает его в SQL-редакторе.

## SQL-редактор

* Подсветка синтаксиса, автодополнение имён таблиц и столбцов, проверка скобок и кавычек.
* **Режим «только чтение» включён по умолчанию**: запросы, изменяющие данные или структуру, блокируются.
  Чтобы выполнить изменение, переключите режим и подтвердите — программа покажет, какие команды опасны
  (например, `DELETE` без `WHERE`).
* Режим транзакции: изменения можно зафиксировать или откатить кнопками.
* `F5` — выполнить скрипт или выделенный текст. Пакеты разделяются `GO`.
* Результаты экспортируются в CSV, Excel и JSON потоком — без ограничения на число строк в окне.
* История запросов и избранное — на вкладках редактора.

## Отчёты и шаблоны

1. В разделе **«Отчёты Word»** выберите подключение, базу и шаблон, заполните параметры.
2. Отметьте форматы: Word, PDF (нужен LibreOffice), Excel, CSV, HTML, Markdown.
3. Нажмите «Сформировать отчёт». Слева виден предпросмотр структуры, внизу — ход выполнения и готовые файлы.

**Код запроса и его результат в отчёте** — три способа:

* в списке шаблонов есть ваши **сохранённые запросы** (из «Избранного» SQL-редактора): выберите запрос, заполните
  его параметры `:имя` и сформируйте отчёт — в нём будет текст запроса, значения параметров, число строк, время
  выполнения и таблица результата; кнопка «Изменить в конструкторе» превратит его в обычный шаблон;
* флажок **«Добавить в конец отчёта код запросов и их результаты»** — приложение для любого шаблона;
* блок **«Код запроса и результат»** в конструкторе шаблонов (можно отключить код или результат и ограничить число
  строк); на вкладке «Источники данных» кнопка **«Из избранного…»** создаёт источник из сохранённого запроса.

В тексте запроса значения после слов вроде `password=` и `token=` скрываются. Как и все отчёты, запрос должен
только читать данные.

В **«Конструкторе шаблонов»** настраиваются оформление, параметры, источники данных (SQL-запрос, таблица или
хранимая процедура) и блоки отчёта: заголовки, текст, таблицы, статистика, диаграммы, выводы. В тексте можно
использовать переменные: `{{date}}`, `{{database}}`, `{{param.имя}}`, `{{rows.источник}}`.

## Конвертер файлов

Перетащите файлы или папки в окно конвертера, выберите формат результата и нажмите «Преобразовать». Кнопка
«Таблица совместимости» показывает, какие преобразования возможны и что при них теряется. Исходные файлы никогда не
изменяются. PDF доступен только как результат.

## Автоматизация

### Задачи по расписанию

Раздел **«Автоматизация» → «Задачи»**: формирование отчёта, экспорт таблиц, резервное копирование, проверка
доступности сервера, сбор размеров таблиц, SQL-сценарий. Расписание: однократно, через интервал, ежедневно, по дням
недели, ежемесячно, после подключения.

Встроенный планировщик работает, **пока программа открыта**. Чтобы задача выполнялась при закрытой программе,
выберите её и нажмите «Планировщик Windows…» — будет создано задание Windows, которое запускает задачу без окна.
Одна и та же задача не выполняется одновременно дважды, даже если её запустили и программа, и Планировщик Windows.

### Резервные копии

Вкладка «Резервные копии»: создание полной копии (`COPY_ONLY` — не нарушает план резервного копирования
администратора), проверка копии, история, очистка старых копий этой программы и восстановление **в новую базу**.
Путь к папке указывается **на сервере** — файл пишет служба SQL Server.

### SQL-сценарии

Сценарий — сохранённый SQL с параметрами `:имя`. Изменяющий сценарий выполняется, только если отмечено
«Разрешить изменения» и текст SQL подтверждён (после правки текста подтверждение снимается). По умолчанию изменяющий
сценарий выполняется в транзакции и откатывается при ошибке.

### Уведомления

Ошибки и замечания задач появляются на вкладке «Уведомления», счётчик — в строке состояния (`Ctrl+Shift+N`). Если
окно не активно, важные уведомления показываются в области уведомлений Windows (можно отключить в «Настройках»).

## Мониторинг

Доступность и время отклика сервера, размеры баз, крупнейшие таблицы, активные запросы и блокировки (при наличии
права VIEW SERVER STATE), график отклика, ошибки программы. Показатели без данных или без прав не выдумываются —
вместо них выводится пояснение.

## Сравнение баз

* **Структура:** выберите исходную базу (образец) и целевую. Различия группируются: только в исходной, только в
  целевой, различается, сравнить нельзя.
* **Данные:** укажите две таблицы и ключ. Показываются новые, удалённые и изменённые записи.
* **Скрипт синхронизации** только формируется и показывается. Удаления в нём закомментированы. Выполнить скрипт
  можно лишь после ввода имени целевой базы; он выполняется одной транзакцией и откатывается при ошибке.
  **Перед выполнением сделайте резервную копию целевой базы.**

## Документация базы

Раздел **«Документация»**: выберите базу, отметьте разделы и форматы (Word, PDF, HTML, Markdown) и нажмите
«Сформировать». Документ содержит обзор, схему связей, таблицы со столбцами и ключами, представления, процедуры,
функции и триггеры. При повторном формировании добавляется раздел «Изменения с прошлой версии документации».

## Настройки

* Папки по умолчанию для отчётов, конвертации и документации, лимиты строк, тайм-ауты, путь к LibreOffice.
* **Резервная копия настроек**: экспорт и импорт подключений (без паролей), шаблонов, избранных запросов,
  SQL-сценариев и задач. При импорте задачи приходят выключенными, подтверждения сценариев снимаются.
* «Сбросить настройки» возвращает значения по умолчанию (подключения, шаблоны и задачи не затрагиваются).

## Сочетания клавиш

| Клавиши | Действие |
| --- | --- |
| Ctrl+1 … Ctrl+9 | Разделы в порядке меню слева |
| F1 | Справка |
| Ctrl+Shift+N | Уведомления |
| F5 | Выполнить запрос в SQL-редакторе |

## Частые вопросы

**Почему не работает PDF?** Нужен LibreOffice (бесплатный). Программа ищет его сама: путь из настроек, PATH,
реестр Windows, папки программ на любом диске (в том числе «LibreOffice 7»), установку только для пользователя и
переносные версии. Если не находит — «Настройки» → «Путь к LibreOffice» → «Папка…» и выберите папку LibreOffice
(подходит и основная папка, и вложенная `program`). Где именно программа искала, показывает `bat\find_libreoffice.bat`
или строка состояния под этим полем. После смены пути перезапуск не нужен.

**Почему не видны некоторые таблицы или определения процедур?** SQL Server показывает только объекты, на которые у
учётной записи есть права. Для текстов процедур нужно право VIEW DEFINITION.

**Задача не выполнилась ночью.** Если программа была закрыта, встроенный планировщик не работал — запуск отмечен в
истории как пропущенный. Создайте задание Планировщика Windows или включите «выполнить при следующем запуске».

**Где журналы?** «Справка» → «О программе» → «Открыть журналы». Там же — «Собрать диагностический архив» для
администратора (пароли в нём замаскированы; журналы могут содержать имена серверов).
